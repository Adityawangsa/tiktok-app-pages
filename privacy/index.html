Data Terenkripsi & Akses Mandiri

Ringkasan Utama

Aplikasi ini hanya mengakses informasi dasar akun TikTok (nama pengguna, ID akun) untuk keperluan autentikasi, serta mengunggah video beserta judul/deskripsi yang disiapkan pemilik di Google Sheets. Token akses disimpan secara terenkripsi di Google Apps Script Properties milik pemilik dan tidak dibagikan ke pihak ketiga mana pun. Data tidak digunakan untuk tujuan lain selain mempublikasikan konten terjadwal ke akun TikTok yang terhubung.

Data yang Diakses

Hanya informasi dasar profil TikTok (nama pengguna & ID akun) untuk memvalidasi kepemilikan akun saat integrasi OAuth.

Penyimpanan Aman

Token otorisasi disimpan secara terenkripsi di dalam Script Properties Google Apps Script milik pengguna sendiri.

Tanpa Pihak Ketiga

Data tidak pernah dipindahtangankan, dijual, atau dibagikan ke entitas eksternal mana pun selain API TikTok resmi pemilik.
